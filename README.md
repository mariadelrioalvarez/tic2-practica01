🎓 Comparativa de Universidades y Grados Universitarios

Proyecto web | TIC II

Desarrollo de una página web dedicada a la investigación, presentación y comparación del grado universitario de Administración y Dirección de Empresas (ADE) en tres universidades: ICADE, CEU San Pablo e IE University.

El proyecto busca ofrecer a los estudiantes una herramienta visual, intuitiva y accesible que facilite la búsqueda de información y la comparación de distintas opciones universitarias antes de tomar una decisión académica.

🎯 1. Descripción y objetivos

El proyecto consiste en el diseño y desarrollo de una página web informativa centrada en el grado de Administración y Dirección de Empresas (ADE), impartido en tres universidades diferentes:

Universidad Pontificia Comillas (ICADE).
Universidad CEU San Pablo.
IE University.

El objetivo principal es recopilar, organizar y presentar información relevante sobre estas instituciones, sus titulaciones, planes de estudio, procesos de admisión y características académicas.

Se pretende crear una plataforma de consulta que permita a los estudiantes, especialmente a aquellos que están finalizando la etapa de Bachillerato, conocer las diferentes alternativas universitarias y comparar sus características de forma sencilla.

La página apuesta por una navegación intuitiva, una estructura organizada y una presentación visual que facilite la comprensión de la información.

✨ 2. Funcionalidades principales

Entre las principales funcionalidades de la página web destacan:

🏛️ Información universitaria: consulta de datos y características de ICADE, CEU e IE University.
📚 Exploración de titulaciones: información específica sobre el grado de ADE en cada institución.
⚖️ Comparación académica: análisis de planes de estudio, asignaturas, créditos y criterios de admisión.
